# Tauross 1.0.0

The first public release of Tauross, a compact phone mirroring app for macOS 14 and later.

- Mirror and control Android devices over USB or ADB Wi-Fi, including pairing on Android 11+.
- Discover connected Android emulators and USB iPhone/iPad screen sources.
- View each selected device in a separate resizable window with native macOS controls.
- Adjust Android resolution, frame rate, bitrate, input control, stay-awake, and touch indicators in Settings.
- Save PNG screenshots and use keyboard/mouse input on Android.
- A white, English-only interface with moss green accents and a clear Mirroring status.
- Bundled ADB and scrcpy-server: no separate command-line tools required.
- Signed in-app updates via Sparkle, including Check for Updates in the Tauross menu.

## Current limits

- One active mirror session at a time.
- iOS is USB and view-only; the capture implementation still needs validation on physical hardware.
- Audio forwarding, video recording, and iOS Wi-Fi are not included.
- Android text input has limitations with complex Unicode and IMEs.
- This build is ad hoc signed and is not Apple notarized. Sparkle update feeds and archives are signed with Tauross's dedicated Ed25519 key.
