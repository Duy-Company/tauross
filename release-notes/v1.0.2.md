# Tauross 1.0.2

- Add Android clipboard sharing: text copied on Android is automatically available to paste on macOS. Paste Mac clipboard text into the mirror with **⌘V**, including Vietnamese and emoji.
- Support **⌘C**, **⌘X**, and **⌘A** in the Android mirror for copy, cut, and select all. Clipboard sharing requires input control and supports text; injected copy, cut, and paste require Android 7 or later and app support.
- Add **Settings → Saved Captures → Change Capture Folder…** and remember the selected folder for screenshots and recordings. Folder changes apply to new captures; existing files and recordings already in progress keep their original location.
- Use `~/tauross` as the default capture folder when no legacy folder exists. Updates preserve an existing `~/.tauross` folder.
- Show the actual save location in screenshot and recording notices.

This build is ad hoc signed and is not Apple notarized. Sparkle update feeds and archives remain signed with Tauross's dedicated Ed25519 key.
